apart 0.6.0
Drive your signed-in browser from the terminal.
→ Agents: run apart guide first. It has the rules.
Run scripts
apart repl '<js>' Run a Playwright-style script
--file <path> Read the script from a file, - for stdin
--browser <name> chrome, arc, dia, brave, edge or headless
--headless, --chrome Shortcuts for --browser
--agent <name> Who owns the tabs this run leaves open
--timeout <ms> Default 120000, at most 600000
Set up
apart setup Choose the default browser, load the extension
apart doctor Check everything and say what to fix
apart extension-path Print the extension folder
Settings
apart config Show settings
apart config default-browser <name>
apart config keep-tabs on|off
Daemon
apart daemon status|start|stop|restart
