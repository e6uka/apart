Settings

apart lets the agent in your terminal open and use tabs in this browser. It works only with tabs it opens itself, in the pink apart tab group.

Connection

Default browser

Which browser apart repl uses when a script does not say. Add --browser <name> to choose for one run.

Default browser

This browser's name

Scripts pick a browser by name, as in apart repl --browser arc. apart names each browser after the app. Set your own to use two profiles of the same browser at once.

When a script ends

Scripts can always close a tab themselves with closeTab. Headless tabs always close.

When a script ends

First-time setup

  1. Install the command line tool:
    npm install -g apart-browser
  2. Choose the default browser:
    apart setup
  3. Check that everything is connected:
    apart doctor
  4. Optional, for gstack's /browse and /scrape:
    apart setup --gstack

Daemon port

Change this only if something else on your computer already uses port 27170.

What apart keeps

  • The last 200 runs: when they ran, which browser they used, how long they took, whether they worked, and any error.
  • The pages each run opened, without query strings or anything after a #.
  • Your port setting, default browser and the connection status.
  • Nothing else. It stays in this browser and in apart's folder on your computer, and is never sent anywhere. Clearing removes it from both.
