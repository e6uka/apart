Settings

apart lets the agent in your terminal open and use tabs in this browser. It works only with tabs it opens itself, in the pink apart tab group.

Connection

First-time setup

  1. Install the command line tool from the apart folder:
    ./install.sh
  2. Check that everything is connected:
    apart doctor
  3. Optional, for gstack's /browse and /scrape:
    ./install.sh --gstack

Daemon port

Change this only if something else on your computer already uses port 27170.

What apart keeps

  • The last 200 runs: when they ran, how long they took, whether they worked, and any error.
  • The pages each run opened, without query strings or anything after a #.
  • Your port setting and the connection status.
  • Nothing else. It all stays in this browser and is never sent anywhere.
